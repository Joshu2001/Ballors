# Ballors realistic footballer assets

Place licensed, rigged glTF binary models here:
- outfield-1.glb through outfield-11.glb
- goalkeeper.glb

Models should face +Z, stand on Y=0, use a neutral standing pose and contain idle/run clips for gameplay. The loader normalizes character height to 1.8 world units. Use physically based materials and compressed textures where possible.

No third-party player likenesses, club kits or proprietary EA assets are included. Obtain appropriate model and likeness rights. Missing models automatically fall back to the existing procedural footballers.
